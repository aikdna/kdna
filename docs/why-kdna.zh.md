# 为什么是 KDNA

文字与排版有文档（`.md`、`.pdf`），数据与测算有电子表格，现场表达有幻灯片，互联信息有网页（HTML），确定性逻辑有代码。每一种重要的人类表达，最终都拥有了契合自身结构的文件形态。

唯独我们在长期实践中最看重的**思考、判断、取舍次序、适用边界与审美品味**，过去一直没有属于自己的独立文件形态。人们已经在用 AI 写作、规划、设计、写代码和做决策，但真正决定方向和质感的核心判断，却散落在聊天记录、临时指令和零散习惯里——换一次会话就丢掉前因后果，换一个工具就得重新调教，把结论发给同事却丢掉了成立的前提和底线。

当 AI 让文章、页面、代码等表面成品的生成越来越便宜，真正稀缺、真正拉开结果差距的，恰恰是上游那套思考、判断与品味。KDNA（`.kdna`）因此把它们确立为一种可以独立保存、给人细读、交给 AI 采用并持续演进的**“作品”**。

## 回答可以很通顺，却悄悄抹掉真正的判断

通用大模型非常擅长写出四平八稳、谁看了都不反感的文字。但当你只让它“帮我改好一点”或“给个建议”时，它常常在保持表面流畅的同时，把你最关键的立场、取舍标准或停手底线悄悄磨平。

《KDNA 白皮书》`v1.0.2`（`judgment:origins`）记录过一个很典型的真实失真：某套诊断方法原本规定，用一张四格评估表专门观察**外部协作方**此刻的真实约束和风险敞口；但在一次 AI 辅助改写中，模型完整保留了原来的四格框架和术语，却把观察对象悄悄替换成了**提案方自己**的内部准备度。文字和表格看起来完好无损，判断真正盯住的对象却已经彻底翻转。

一份真正的判断作品，靠四个彼此咬合的部分守住判断不跑偏：

| 核心追问 | 一份 `.kdna` 作品明确保存什么 |
| --- | --- |
| **你真正盯住什么？** | 不能被悄悄替换的观察对象、关键信号与问题焦点 |
| **好目标冲突时，先保什么、放弃什么？** | 明确的取舍优先序与愿意付出的代价 |
| **到哪里必须停手？** | 适用条件、例外情况、常见误用与交回给人的分界线 |
| **遇到反例怎么成长？** | 清晰的版本号（`1.0.0` → `1.1.0`）与可读的修订差异 |

这四部分缺一不可：只有观点没有边界，就会到处瞎套；只有喜好没有理由，就既没法讨论也没法传承；只有修改没有版本脉络，时间一长连自己都忘了当初为什么这样定。

## 无论六条精炼品味，还是完整领域体系，都是独立作品

KDNA 不是要把一个人的一生塞进一个文件，也不是“克隆人格”。同一个人完全可以分别为写作品味、界面审美、代码评审、商业谈判各自维护一份边界清楚的 `.kdna` 作品——哪怕只有六七条围绕具体处境提炼出的精炼判断，只要讲清了主张、依据、取舍和停手线，它就是一份完整、地道的 `.kdna` 作品。

存成 `.kdna` 之后，这份判断自然拥有三件过去没有的事：

- **人可以先亲眼读懂**：在 [KDNA Reader 桌面版](https://aikdna.com/zh/downloads)里直接浏览全局脉络，逐条审视主张、依据与边界。
- **AI 可以带着前提采用**：兼容的 Agent 先读目录再按需选取相关判断，自动带上支撑前提、限定条件和冲突张力，不会断章取义。
- **完全归你自己持有与保护**：本地独立文件，不绑定任何模型或云端平台，需要保密的作品可直接本地离线口令加密（`kdna protect`），**永久无需注册在线账号**。
