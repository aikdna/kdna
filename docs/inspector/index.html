KDNA Asset Inspector

Open a .kdna file to see its manifest, version tuple and judgment catalog.

Private by design — parsing happens entirely in your browser, offline; the file is never uploaded and no account is needed.

What this page reads

It reads the current 0.6.0 native container (kdna.json plus sections/pack-N.kdnab) and the older single-payload.kdnab layout. It shows the public manifest, the version tuple, the judgment catalog and payload table digests.

It does not decode payload frames, verify signatures or keys, or decrypt anything. An encrypted / password-protected payload is reported as such and stays unreadable here. A valid container proves structure, not judgment quality.
