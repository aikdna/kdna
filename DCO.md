# KDNA DCO Policy

All commits to this repository must carry a DCO sign-off matching the commit author.
GitHub squash merges must use an email matching the DCO sign-off identity.

Automated dependency commits authored by `dependabot[bot]` are not merged
directly. A maintainer who accepts an update must reproduce it in a
maintainer-authored commit signed with `git commit -s` and merge that commit.
There is no blanket bot exemption.

See CONTRIBUTING.md for details.
