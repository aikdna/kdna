# R2 public semantic implementation candidate

The R2 definition is the basis of this unpublished candidate. Public machine semantics reside only in `../public-semantic-source.json`; this directory supplies the human-readable definitions, exclusions, mechanism roles and explicit counterexamples needed to interpret that source. A generated schema pass does not establish faithful content, truth, actual observations, model quality, a user's adoption, implementation acceptance or release.

The definition reference files retain submission-time wording and historical provenance paths. Those historical paths are not dependencies of the published formats or runtime. Read this directory's FIELD-DICTIONARY, COMPOSITION, REFERENCE-REGISTRY and PUBLIC-PROJECTION together; the two concept drafts supply full category meanings and exclusions. Later R2 clauses take precedence over earlier concept wording.

Public fixtures in review-fixtures are engineering semantic views, not formal business assets, model outputs or proof of observed events. In particular, authored-merge-expected preserve/declaration variants establish Policy structure only: their single-field changes do not establish whole-asset prose consistency. An observed-private-source example assumes real records for a paper scenario; it does not prove such records exist.

Implementation and exact version issuance are pending. Historical accepted snapshots are never rewritten by this candidate. Migration is explicit, with author/content review; missing labels, roles, full questions, scopes, history or provenance are never invented.
