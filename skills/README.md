# Bundled Agent Adapter — historical compatibility copy

> **Status:** Unassessed compatibility copy for the published CLI **0.36.1**
> loading contract. It is not the current grammar.3 Loader.

This directory preserves the adapter copy used by published setup code. Its
`plan-load` and `load --profile=compact --as=json` examples belong to CLI 0.36.1
and matching published-line assets. Current CLI candidates correctly reject
these old command forms. Do not install this copy as a current or broad-trigger
discovery Skill.

For current explicit-file consumption, use the canonical
[kdna-skills entry](https://github.com/aikdna/kdna-skills#readme) and
[Loader Skill](https://github.com/aikdna/kdna-skills/blob/main/kdna-loader/SKILL.md).
Obtain the exact Loader/MCP combination and complete installation inputs stated
there; copying a Skill alone does not install a runtime or grant permission.
The [source/version guide](../docs/core-read-current-status.md) separates local
unpublished candidates, remote source and published history.

The canonical adapter accepts one explicitly selected file. It does not scan a
global store, select a judgment autonomously or hide active use. Native Host
delivery, semantic adoption and real human acceptance remain `not_run` until
separately observed for the exact Host/version.

Future packaging must verify byte equality with the accepted `kdna-skills`
source and pass the Host adapter contract before a replacement copy can be
described as supported. This historical copy is not that replacement.
